Smart Home Webhooks

So verbindest du den AuraMed Telegram Bot mit deinem Smart Home System.

1. Home Assistant (Nabu Casa)

Wenn du Home Assistant nutzt, ist der einfachste Weg über einen Nabu Casa Webhook. Das geht so:

  1. Gehe in Home Assistant auf Einstellungen > Automatisierungen & Szenen.
  2. Klicke auf Automatisierung erstellen.
  3. Wähle als Auslöser (Trigger) Webhook aus.
  4. Home Assistant generiert nun eine URL. Wenn du Nabu Casa nutzt, lautet diese z.B. https://hooks.nabu.casa/abcd1234....
  5. Kopiere diese URL und füge sie in den AuraMed Telegram-Bot ein!
Wichtig: Wenn du kein Nabu Casa benutzt, muss dein Home Assistant von außen erreichbar sein (z.B. über Cloudflare Tunnel oder DuckDNS), damit unser Server die Daten an deinen lokalen Webhook senden kann.

2. n8n (Node-RED Alternativen)

Wenn du visuelle Workflows mit n8n baust:

  1. Erstelle einen neuen Workflow und füge den Node Webhook als Trigger hinzu.
  2. Stelle die Methode auf POST.
  3. Kopiere die "Production URL" (z.B. https://n8n.deine-domain.de/webhook/1234...).
  4. Sende diese URL an den AuraMed Telegram Bot.
  5. Sende ein Test-Foto an den Bot. Im n8n Webhook-Node erscheint nun das fertige JSON mit Name, PZN und Verfallsdatum!

3. Ich nutze kein Smart Home (Telegram Only)

Kein Problem! Wenn du AuraMed einfach nur als komfortablen Scanner in Telegram nutzen möchtest, antworte dem Bot bei der Einrichtung einfach mit dem Wort Telegram.

Wir speichern dann keinen Webhook und der Bot schickt dir die Ergebnisse deines Medikamenten-Scans (inklusive Nachbestell-Link) einfach direkt als Chat-Nachricht zurück.
