Schluss mit abgelaufenen Medikamenten.

Die manuelle Verwaltung der Hausapotheke kostet Nerven und birgt Risiken.

⚠️

Das Problem

  • Unübersichtliche Inventur: Wer weiß schon genau, was ganz hinten im Medizinschrank steht?
  • Verfallene Wirkstoffe: Abgelaufene Medikamente verlieren ihre Wirkung oder werden potenziell gesundheitsschädlich.
  • Schlechte Lesbarkeit: Eingeprägte Haltbarkeitsdaten auf Blistern oder Schachteln sind im Alltag oft unleserlich.
  • Mühsame Dateneingabe: Niemand möchte 20 Packungen nach einem Apothekenbesuch manuell in eine App eintippen.
✨

Die Lösung mit AuraMed

  • Ein Foto genügt: Knipse ein Bild der Verpackung, unsere API erledigt den Rest in Millisekunden.
  • Immer informiert: Automatische Push-Warnungen in deinem Smart Home, bevor etwas abläuft.
  • Künstliche Intelligenz: Unser OCR-Fallback liest selbst zerknitterte oder schlecht gedruckte Daten zuverlässig aus.
  • Nahtlose Integration: Perfekt einsetzbar für Home Assistant, n8n, Node-RED oder dein eigenes App-Projekt.

Warum AuraMed?

Entwickelt für maximale Performance und absolute Datensicherheit.

⚡

Local-First & Privacy

Dank intelligenter PZN-Validierung scannen wir einen Großteil der Medikamente lokal. Personenbezogene Daten oder Gesundheitsinformationen verlassen niemals unverschlüsselt dein Zuhause. Die API arbeitet komplett zustandslos.

☁️

Google Cloud OCR Fallback

Unleserliche, zerknitterte Codes oder spiegelnde Oberflächen? Wenn der lokale Datamatrix-Scan fehlschlägt, springt unser KI-gestütztes OCR-Fallback ein und liest das Haltbarkeitsdatum nahtlos als reinen Text aus den Bildpixeln.

🤖

Telegram Bot & Smart Home

Ein strikter "Zero-UI" Ansatz mit maximalem Komfort. Nutze unseren offiziellen Telegram-Bot als bequeme App-Alternative (Foto schicken, Infos erhalten) oder binde die API nahtlos per Webhook als Sensor in dein Home Assistant Dashboard ein.

🔄

BfArM-Datenbank Integration

Wir synchronisieren wöchentlich mit den offiziellen Datenbanken des Bundesinstituts für Arzneimittel und Medizinprodukte (BfArM). So erhältst du nicht nur das Ablaufdatum, sondern auch den exakten Medikamentennamen und verifizierte PZN-Daten.

💻

Developer-Friendly API

Keine komplexen SDKs oder unnötiger Overhead. Eine einfache REST-Schnittstelle mit standardisierten JSON-Responses macht die Integration in jedes bestehende System zum absoluten Kinderspiel.

🔓

Open Source Core

Volle Transparenz und Kontrolle. Der Kern von AuraMed ist quelloffen. Du kannst den Service komplett selbst hosten oder bequem auf unsere hochverfügbare Cloud-API zurückgreifen.
