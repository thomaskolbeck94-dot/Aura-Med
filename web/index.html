cURL Beispiel

Senden Sie das Foto einfach als multipart/form-data. Sie erhalten innerhalb von Millisekunden den geparsten GS1 Code zurück.

curl -X POST https://api.getauramed.de/api/v1/scan \
  -H "x-api-key: aura_live_dein_key" \
  -F "image=@/pfad/zur/medikamenten_schachtel.jpg"
